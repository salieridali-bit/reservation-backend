# 회의실 예약 시스템

Spring Boot 기반의 회의실 예약 시스템입니다.

사용자는 회의실을 등록하고 수정 및 삭제할 수 있으며,
원하는 날짜와 시간에 회의실을 예약할 수 있습니다.

또한 REST API를 제공하여 외부 애플리케이션에서도
회의실 및 예약 정보를 조회하고 관리할 수 있습니다.

---

## 주요 기능

### 회의실 관리

- 회의실 등록
- 회의실 조회
- 회의실 수정
- 회의실 삭제
- 예약이 존재하는 회의실 삭제 방지

### 예약 관리

-- 예약 등록
-- 예약 조회
-- 예약 수정
-- 예약 취소
-- 본인 예약만 수정 및 삭제 기능

### 예약 검증

-- 종료 시간은 시작 시간보다 늦어야 함
-- 동일 회의실 중복 예약 방지

### REST API

- 회의실 CRUD API
- 예약 CRUD API
- API 예외 처리
